## 📌 Technical Scope & Core Concepts

CS50P goes beyond basic syntax, focusing on writing clean, readable, efficient, and thoroughly tested **Pythonic** code. 

### Key Skills Mastered:
* **Pythonic Foundations**: Functions, type hints, conditional branching, and loop control structures.
* **Error Handling & Defensiveness**: Handling runtime exceptions gracefully using `try`/`except`/`else`/`finally` blocks.
* **Modular Code & Libraries**: Utilizing built-in modules (`sys`, `random`, `math`, `csv`) and external third-party PyPI packages (`requests`, `cowsay`, `pyfiglet`).
* **Automated Unit Testing**: Writing automated test suites using `pytest` to test edge cases, functions, and exception handling.
* **File I/O & Data Parsing**: Reading, processing, and writing data using text files, standard CSVs, and image processing (`PIL`/`Pillow`).
* **Regular Expressions (RegEx)**: Pattern matching, validation, and data extraction using Python’s `re` module.
* **Object-Oriented Programming (OOP)**: Building custom classes, encapsulation, properties (`@property`), methods, operator overloading, and inheritance.
